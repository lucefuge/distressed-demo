# DISTRESSED

Подготовленный к GitHub Pages mobile-first каталог на React 19, TypeScript, Vite 7 и Tailwind CSS 4. Без обязательного backend, аккаунтов, оплаты или публикации. Сохранены каталог из Telegram и чёрный логотип с потрескавшейся текстурой на прозрачном фоне.

Production-сборка показывает 15 карточек с названиями, описаниями, брендами, ценами и размерами из публикаций канала с надписью «Неофициальный демонстрационный концепт». Реальные заказы отключены, персональные данные не собираются. Опубликованная демонстрация: https://lucefuge.github.io/distressed-demo/. Инструкция: [DEPLOYMENT.md](DEPLOYMENT.md).

## Запуск

Нужны Node.js **22.18+ или 24+** и npm. Тесты используют встроенную поддержку TypeScript в Node.

```sh
npm install
npm run dev
```

Открыть **http://127.0.0.1:5173/distressed-demo/**. Если порт занят, Vite напечатает фактический адрес. Остановить сервер: Ctrl+C в его терминале.

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm run preview
```

`preview` обслуживает готовую сборку на http://127.0.0.1:4173/distressed-demo/. `npm run format` форматирует исходники. Если системный npm-cache недоступен, в PowerShell перед установкой: `$env:npm_config_cache="$PWD/.npm-cache"`.

## Два отдельных каталога

**В dev-режиме по умолчанию — публикации канала** (`/distressed-demo/`). В `src/products.json` находятся 15 товарных публикаций публичной ленты [DISTRESSED](https://t.me/s/fuckdistressed), полученных 2 ноября 2026: посты 29661–29627 по убыванию. Альбом — одна позиция; повторяющиеся модели в разных постах сохранены отдельно. Это снимок публикаций, а не синхронизированные остатки.

Названия, новая цена, размеры, состояние и артикул (когда указан) перенесены из постов. Карточки ссылаются на исходный пост и дату. Текущее наличие не подтверждено: `available: null`, поэтому фильтр «Только в наличии» в этом режиме возвращает пустую выдачу. Цвета по фото не угадываются. ID `TG-*` — номер публикации, не артикул производителя.

**Отдельный демо-режим только в dev** (`/distressed-demo/?demo=1`, ссылка «Проверить демо») содержит **16 тестовых товаров**. Вымышленные названия, бренды, цены, размеры и все три состояния наличия явно помечены в каталоге, карточках и тексте копирования. Фотографии из канала используются только для иллюстрации тестового интерфейса. Демо не смешивается с публикациями, кнопка продавца для него отключена. Переключение режима сбрасывает фильтры и избранное.

## Возможности

- Категории, бренды, фильтры размера, цены от/до и подтверждённого наличия; сообщение при некорректном диапазоне.
- Поиск по названию, бренду, внутреннему ID и исходному артикулу, сортировка цены, избранное на время сессии страницы.
- Карточка по прямой ссылке, например `/distressed-demo/#TG-29661` в dev и `/distressed-demo/#DEMO-003` в dev-демо, галерея всех снимков, описание, размер и цена. Нативный диалог с доступным заголовком, закрытием Escape, удержанием фокуса и мобильной вёрсткой.
- Копирование многострочного заказа после выбора размера; ручной fallback при недоступном Clipboard API. Реальные обращения к продавцу отключены в интерфейсе. Неизвестное наличие требует уточнения; отсутствующие позиции нельзя выбрать для заказа.
- Загрузка, ошибка с повтором, пустая выдача и fallback для недоступных фотографий; безопасная обработка повреждённых hash-ссылок.

## Файлы и интеграция

- `src/catalog.ts`: Product, CatalogRepository, реальные/демо-данные, чистые функции фильтрации и текста заказа. Замените `list()` на HTTP-запрос к валидирующему серверу, сохранив интерфейс. Возвращаются независимые копии данных.
- `src/telegram.ts`: необязательный bridge к `window.Telegram.WebApp`: `ready`, `expand`, `openTelegramLink` и fallback для обычного браузера. Без SDK сайт полностью работает.
- `src/clipboard.ts`: защита от устаревшего результата и одновременных записей в буфер при смене размера или товара; отложенные операции покрыты регрессионными тестами.
- `src/main.tsx`, `src/style.css`: интерфейс и адаптивная вёрстка.
- `src/*.test.ts`: тесты данных, фильтров, заказов и Telegram bridge с заглушками.
- `public/products`: 41 локальное фото альбомов. `public/distressed-wordmark.png`: чёрная надпись с белыми трещинами на прозрачном фоне; `public/distressed-logo.png`: исходное фирменное изображение в главном блоке.

Для запуска внутри Telegram позже потребуются HTTPS-хостинг, настройка URL у BotFather и подключение официального Telegram Web App SDK перед `main.tsx`. SDK пока не загружается; реальное окружение Telegram не тестировалось. `initData` нельзя считать достоверным без проверки подписи на сервере. Bot API, база, авторизация, оплата и резервирование пока не подключены; токены и секреты в клиент добавлять нельзя.

## Импорт

Локальные HTML-снимки исключены из публикации через .gitignore и находятся в `channel.html` и `channel-*.html`. `scripts/import-channel.mjs` читает `channel.html`, догружает предыдущие страницы и сохраняет 15 позиций с фото. Перед повторным импортом обновите начальный HTML публичной лентой. Скрипт зависит от текущей разметки Telegram и формата цены «Новая цена»; результат нужно проверять вручную. Автоматической синхронизации нет. Никакие сообщения каналу или продавцу при импорте не отправляются.

## Проверки и ограничения

Сводка выполненных проверок: [QA.md](QA.md). Линтер, отдельная TypeScript-проверка, 29 тестов и production-сборка проходят; в браузере проверены ширины **320, 375, 768 и 1440 px**. Полный сброс очищает фильтры, избранную выдачу и сортировку. Закрытие карточки возвращает к каталогу без накопления лишних записей в истории. Критических известных ошибок нет. `npm audit --omit=dev` — 0 уязвимостей. Полный audit отмечает moderate advisory в транзитивном `minimatch` инструментов ESLint/TypeScript ESLint; эти зависимости не входят в клиентскую production-сборку. Принудительные несовместимые обновления не применялись.

Фото и данные сохранены локально; интернет нужен для перехода в Telegram и повторного импорта. Права на публикацию реальных фото перед внешним размещением проверяет владелец проекта. Демонстрационный концепт опубликован с подтверждения владельца. Продавцу сообщения не отправлялись.
